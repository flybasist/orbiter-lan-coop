# Как начать новый проект из этого шаблона

Этот файл нужен только на старте. **Удалите его сразу после выполнения шагов.**

## Шаги

1. Создайте репозиторий из шаблона (кнопка «Use this template» или команда):
   ```bash
   gh repo create flybasist/<имя> --template flybasist/project-template --public --clone
   ```
2. Замените метки во всех файлах. Пример для macOS (для Linux уберите `''` после `-i`):
   ```bash
   grep -rl '{{' . --exclude-dir=.git --exclude=TEMPLATE.md | xargs sed -i '' \
     -e 's/{{PROJECT_NAME}}/<имя>/g' \
     -e 's/{{ONE_LINE}}/<одна строка о проекте>/g' \
     -e 's/{{DATE}}/<ГГГГ-ММ-ДД>/g'
   ```
3. Заполните `README.md` и `docs/`. Подсказки в `<!-- -->` удаляйте по мере заполнения.
4. Удалите ненужные файлы из `docs/` (например, `SECURITY.md`, если безопасность не тема проекта),
   а вместе с ними ссылки на них в `docs/README.md`.
5. Проверьте, что в проекте не осталось меток и подсказок:
   ```bash
   grep -rn '{{\|<!--' . --exclude-dir=.git --exclude=TEMPLATE.md
   ```
6. Удалите `TEMPLATE.md`.

## Что здесь можно менять

Шаблон — только скелет. Состав файлов, названия разделов и подпись автора одинаковы во всех
проектах, поэтому меняйте их в шаблоне, а не в отдельном проекте.
