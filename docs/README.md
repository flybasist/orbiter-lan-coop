### Правила работы над проектом

- Комментарии в коде и вся документация — на русском. Всё, что программа печатает в
  терминал (сообщения, логи, ошибки), — на английском.
- Код должен быть простым и понятным новичку: понятность важнее изящества.
- После любого изменения сверьте с кодом `README.md`, `docs/` и комментарии. Они должны
  описывать текущее состояние, а не прошлое.
- Не оставляйте неиспользуемых функций, файлов и зависимостей.
- Команды `docker` (сборку, запуск, остановку) выполняет владелец проекта и присылает вывод.
  ИИ-агент docker сам не запускает: проверяйте код статически.
- Коммиты и отправку в git делает только владелец проекта.
- Файл результата проверочной сборки всегда один и тот же — `{{PROJECT_NAME}}.out` — и он
  перечислен в `.gitignore`.
