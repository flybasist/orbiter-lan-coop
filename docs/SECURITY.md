# Безопасность

OLC рассчитан на компьютеры в одном классе и одной локальной сети. Безопасность здесь —
это прежде всего ясное понимание, чего протокол не делает.

## Что защищено

- Плагин принимает подключения только когда пользователь явно включил роль хоста.
- Клиент управляет только кораблём, который хост ему назначил (планируется).
- Сетевые пакеты проверяются на размер и формат перед разбором (планируется): битый или
  чужой пакет не должен ронять Orbiter.

## Что НЕ защищено

- Нет аутентификации: любой компьютер в той же сети может подключиться к хосту.
- Нет шифрования: данные идут по сети в открытом виде.
- Нет защиты от подмены пакетов и от намеренных помех внутри сети.

## Рекомендации

- Не открывайте порт OLC в интернет и не пробрасывайте его на роутере.
- Используйте OLC в доверенной сети класса или лаборатории.
- В брандмауэре Windows разрешайте порт OLC только для частной сети.
