# Текстуры и дополнения для пакета испытаний

Исследование задачи 3.15 (решение 43): откуда берут текстуры планет и дополнения, сколько они
весят, под какой лицензией и что можно положить в архив для испытателей. Данные собраны
2026-11-18 с открытых страниц; страницы форума Orbiter для агента отдают 403, поэтому
**лицензии пакетов текстур не подтверждены** (см. раздел 3).

## 1. Что нужно испытаниям

Испытания (задача 3.7) — сближение и стыковка двух DeltaGlider на орбите. Для них нужны:

- Orbiter базового коммита с D3D9Client и плагином OLC — собирается нами, текстур не требует;
- ядра SPICE (`Kernels`, `orbiter.bsp` 1,6 ГБ) — без них Orbiter не стартует;
- базовые текстуры планет (в первую очередь Земля): в репозитории Orbiter их нет, без них D3D9Client
  при старте показывает окно «Surface textures are missing» (`QUICKSTART.md`, раздел 4);
- высокого разрешения поверхности для орбитальной стыковки не требуют: пакеты высокого
  разрешения заметны только у самой поверхности, на высоте Orbiter берёт грубые уровни.

## 3. Лицензии

- Сам Orbiter — MIT (файл `LICENSE` репозитория), D3D9Client — LGPL. Их можно класть в архив
  с сохранением текстов лицензий.
- Страница загрузок `orbiter-mods.com` называет MIT только для ядра Orbiter; **для пакетов текстур
  лицензия на ней не указана**. Страницы пакетов на форуме Orbiter агент прочитать не смог (403).
- Исходные данные (спутниковые снимки и рельеф NASA и других) обычно свободны, но пакеты —
  работа авторов дополнений, и условия переиздания у каждого свои.
- Вывод: пока лицензия пакета не подтверждена владельцем по странице автора, его нельзя класть в
  наш архив; безопасно давать испытателям **ссылку и инструкцию**, а не копию.

## 4. Предложение по составу пакета

1. В архив кладём: Orbiter базового коммита с D3D9Client (MIT, LGPL), плагин OLC, настройки,
   сценарии, инструкции.
2. Ядра SPICE — скачиваются по ссылкам с `cdn.openorbiter.space`; в архив можно положить, если
   владелец одобрит (лицензия ядер NASA/JPL свободная, но на сайте Orbiter не оговорена).
3. Базовые текстуры планет — из установки Orbiter 2016 по ссылке с форума; в архив — только после
   подтверждения лицензии.
4. Высокое разрешение не включать вовсе: для орбитальной стыковки оно не нужно, а Земля целиком —
   33 ГБ.
5. Пока нет разрешения на текстуры, испытателям подходит пустой каталог `Textures\Earth`
   (Земля без текстуры, `QUICKSTART.md`, раздел 4).

Решение по списку загрузок — вопрос Q10 в `QUESTIONS.md`.
