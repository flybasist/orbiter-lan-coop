# Исследование

Сведения собраны 4–5 ноября 2026 года. Цифры по коду — для базового коммита Orbiter
`9721ab8d`. Как устроено ядро — в [ORBITER-INTERNALS.md](ORBITER-INTERNALS.md).

## 1. Orbiter сегодня

- Бесплатный космосимулятор с реалистичной физикой. Автор — Martin Schweiger. С 2021 года
  код открыт на GitHub, лицензия MIT.
- C++ под Windows: окна и ввод — Win32 API и DirectInput, графика — DirectX 9 (D3D9Client).
  Сборка — CMake и Visual Studio.
- Объём кода (C/C++/Lua, с комментариями):

  | Часть | Строк | Что внутри |
  |---|---|---|
  | `Src/Orbiter` — ядро | ~88 тыс. | физика, время, сцена, ввод, MFD |
  | `Src/Celbody` | ~145 тыс. | эфемериды планет и спутников, библиотека SPICE |
  | `Src/Vessel` | ~44 тыс. | штатные корабли |
  | `OVP/D3D9Client` | ~68 тыс. | графический клиент |
  | `Orbitersdk`, плагины, `Utils`, `Extern` | ~130 тыс. | SDK, плагины, утилиты, Lua, imgui, zlib |

- Активность: 2332 коммита, 43 автора за всё время, около 10 активных за последний год
  (86 коммитов). Около 2000 звёзд и 290 форков на GitHub.
- Документация: руководства пользователя и разработчика дополнений (`Doc/`), doxygen в
  заголовках SDK. Внутреннее устройство ядра нигде не описано.

## 2. Прошлые попытки мультиплеера

| Проект | Годы | Как устроен | Итог |
|---|---|---|---|
| OMP (Orbiter Multiplayer Project) | 2006–2017 | Сервер «вселенной» + клиенты; каждый считает физику своего корабля, состояния по UDP между клиентами, синхронизация часов | Не доведён, последняя версия OMP 2016 под 32-битный Orbiter |
| OMX | после OMP | Продолжение OMP, GPLv2 | Узкое распространение |
| Multiplayer Lite | ~2024 | Веб-сервер + плагин-клиент, синхронизация сессий | Простая синхронизация, не совместный полёт |
| Project Hamac, IRCMFD, Multiorb | разные | Экспериментальные | Заброшены |

Общая проблема — физика на каждом компьютере своя, поэтому миры расходятся, а стыковка
кораблей разных игроков и ускорение времени работают плохо. Ни одно решение не работает
с Orbiter 2024 x64.

Чем отличается OLC: одна физика на хосте; современный Orbiter с открытым ядром, куда можно
предлагать хуки; узкая цель — LAN, 2–4 человека.

## 3. Linux и macOS

- **Linux через Wine/DXVK/Proton** уже работает (сообщество, OrbiterWiki). Проверим на
  Steam Deck и Linux x86.
- **Нативный Linux** делает сообщество: ветка `linux` (Gondos, по сообщениям на форуме) и PR #561 с переходом на SDL3
  (открыт с февраля 2025, +7,9/−10,6 тыс. строк). В `CMakePresets.json` есть пресеты сборки
  через `winegcc`. В рамках OLC нативный порт не делаем.
- **macOS** — только через виртуальную машину с Windows или CrossOver.

## 4. Лицензии

| Часть Orbiter | Лицензия |
|---|---|
| Ядро, SDK, штатные корабли и плагины | MIT |
| XRSound | MIT |
| `OVP/D3D9Client` | GPLv3 / LGPLv3 на выбор |
| Библиотеки в `Extern` | свободные лицензии (MIT, zlib и др.), шрифты — SIL/FFC |

- OLC линкуется только с SDK (MIT), поэтому может выходить под GPLv3.
- `Orbitersdk.lib` — статическая библиотека, её код попадает в DLL плагина. В релиз нужно
  класть MIT-уведомление Orbiter (см. [CREDITS.md](CREDITS.md)).
- MIT не даёт прав на название: OLC — дополнение «для Orbiter», не официальная часть.
- Если когда-нибудь понадобится встроить OLC в ядро (MIT), автор может перелицензировать код;
  при приёме сторонних PR это нужно оговорить заранее.

## 5. Релизы Orbiter

- Последний стабильный релиз — тег `2024` (31.12.2024).
- Тег `latest` — ночная сборка из `main`, перевыпускается автоматически.
- С релиза 2024 в `main` 131 коммит. Важное для OLC: столкновения кораблей (`CollisionCore`,
  10.2026, первая часть из трёх), диалоги на ImGui, `oapiGetKeyState`, ввод с клавиатуры в
  ExtMFD, время через `std::chrono`, исправление интерполяции эфемерид.
- Изменения SDK с 2024 года только добавляющие: старые плагины грузятся в `main`, новые
  функции в релизе 2024 недоступны.
- На GitHub открыта веха «2026 Release» со сроком 28.12.2026. Официального анонса нет.
