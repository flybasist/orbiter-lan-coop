# CHANGELOG

Изменения после `v0.1`. Протокол и поведение плагина не менялись: пакет раунда 1 остаётся
актуальным.

  описаны в `docs/ru/ORBITER-INTERNALS.md`, раздел 15.

- **Сервер OLC без графики под Wine** на Linux x86 проверен со стыковкой (задача 3.29).
- **Без дублей кода** (задача 3.31): сборка UDP-пакета, сравнение связок `DOCK`, общее для хоста и
  клиента в плагине (`plugin/common.h`), значения по умолчанию настроек — из констант ядра. Поведение
  то же, проверено на стенде.
- **Сценарий** `tools/scenarios/Two Shuttle-A Moon.scn` — два Shuttle-A на Луне; в пакет раунда 1 не
  входит.
- **Документы:** `docs/ru/ORBITER-VERSIONS.md` (Orbiter 2016, 2024 и сборка OLC для испытателей),
  права агента для автономной работы (`docs/ru/README.md`), сверка документов с кодом.

## v0.1 — Первая версия для испытаний людьми (2026-11-19)

Тег `v0.1` в GitHub. Эта версия передаётся в космокружок: пакет испытаний раунда 1 и методика.
Подробная история работ — `docs/ru/PLAN.md` и git; здесь — что входит в версию.

### Что есть

- **Плагин `OrbiterLanCoop`** на официальном SDK Orbiter (базовый коммит `a7a3396e`, Windows x64):
  роли хост и клиент, пункт «OLC - LAN co-op» в Launchpad, настройки в `Config\OrbiterLanCoop.cfg`.
- **Общий мир по LAN.** Физику считает только хост; 60 раз в секунду он рассылает состояния кораблей,
  клиент показывает их с задержкой 30 мс и сглаживанием. Общие время и пауза. Кнопка «Connect»:
  клиент получает мир хоста и сам запускает его; корабли незнакомых классов убираются до запуска.
- **Свой корабль у каждого пилота.** Взять свободный корабль фокусом (F3), отпустить Ctrl+Alt+U;
  чужой — только просмотр. Клавиши и джойстик пилота уходят хосту, разовые нажатия (автопилоты,
  шасси, конус) — тоже. Обрыв связи: органы управления отпускаются, корабль 60 с ждёт пилота.
- **Стыковка и расстыковка** повторяются у всех, в том числе у подключившегося позже.
- **Механизмы и частоты.** Шасси, конус и другие анимации, частоты NAV и транспондера корабля видят
  все участники.
- **Руководитель полётов** (имя задаёт настройка хоста `Director`): общая пауза и ускорение, сводка
  игроков на экране, сохранение мира Ctrl+Alt+S и автосохранение, запись полёта штатной клавишей
  Ctrl+C. Сервер может работать без графики, в том числе на одной машине с клиентом РП.
- **Протокол версии 7** — `docs/ru/PROTOCOL.md`; клиента другой версии протокола хост не принимает.
- **Пакет испытаний** — `tools/package/make-package.ps1` (три архива), установка — `docs/ru/PACKAGE.md`,
  методика — `docs/ru/TEST-PROCEDURE.md`, памятка — `docs/ru/PILOT-GUIDE.md`.
- **Инструменты:** `olc-netcheck` (проверка сети), `olc-smoothing` (модель сглаживания),
  `olc-doccheck` (пары документов RU и EN), `OlcRigTest` и скрипты стендов `tools/stands/`.
- **Тесты ядра** без сторонних библиотек (`ctest`), сборка в GitHub Actions.

### Известные ограничения

- Только Windows x64 и локальная сеть; протокол не защищён и не для интернета.
- Раскладка клавиш у участников должна совпадать; щелчки по панели кабины не передаются (ретро-створки
  DeltaGlider у клиента не открыть).
- Ускорение времени рядом с кораблями — только при `VesselCollision = FALSE`.
- Внутреннее состояние модуля на копии корабля не меняется (например, точки касания шасси у клиента).
- Интерфейс плагина на английском.
