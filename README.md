# orbiter-lan-coop (OLC)

Совместные полёты в космосимуляторе [Orbiter](https://github.com/orbitersim/orbiter) по
локальной сети: несколько человек в одной симуляции с разных компьютеров.

> Статус: исследование и проектирование. Кода плагина пока нет — идёт подготовка прототипа.

## Как это работает

OLC — это плагин для стандартного Orbiter, а не изменённая версия симулятора.

| Роль | Что делает |
|---|---|
| Хост (компьютер преподавателя) | Считает физику всех кораблей, управляет временем и паузой |
| Клиент (компьютер ученика) | Показывает мир хоста, отправляет хосту команды своего корабля |

Физика одна на всех, поэтому миры участников не расходятся, а стыковка кораблей двух
игроков работает так же, как в одиночной игре.

## Что нужно

- Windows 10/11 x64 на всех компьютерах (Linux — через Wine/Proton, в роли клиента).
- Одинаковая сборка Orbiter и одинаковый набор дополнений на всех компьютерах.
- Компьютеры в одной локальной сети.
